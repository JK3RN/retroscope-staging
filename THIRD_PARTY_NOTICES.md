## Libraries used at run time (not included)

RetroScope links dynamically against system libraries provided by your distribution. They are
not part of this repository or of the release archive.

| Library | Used for | License |
| --- | --- | --- |
| SDL2 (tested with sdl2-compat over SDL3) | Window, rendering, input, timers | zlib |
| libpulse (PulseAudio client library, also used with PipeWire-Pulse) | Audio capture | LGPL-2.1-or-later |
| C library and libm (e.g. glibc) | Runtime, math | LGPL-2.1-or-later with exceptions (glibc) |

Dynamic linking keeps these libraries replaceable, as the LGPL requires for distributed
binaries. Their license texts are installed with the respective packages.

## Tools used only for tests and documentation (not linked)

PipeWire, WirePlumber and pipewire-pulse (MIT) run as private instances in
`make audio-smoke` and `make showcase`. ImageMagick and FFmpeg are used by `make showcase` to
convert screenshots. `grim` and Hyprland capture the screenshots.
